# Archived pre-OMF prototype

These files are retained from the repository's earlier prototype to preserve
its tokenizer and inference code. They are not used by the current Pico
training recipe, are not compatible with OMF checkpoints, and are not a
supported inference path. The required `pico-15m.pt` weights are not included.

The older repository description reported training and evaluation details that
are not verified by artifacts in this repository. Do not treat those claims
as documentation of the current OMF model.
